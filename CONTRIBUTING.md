# Contributing

Issues and pull requests are welcome. New example applications are too (face swapping, avatars, anything Ref2VA can drive
from a reference and a video): add the prompt and any server changes, and describe how to run it in the README.

- By submitting a contribution you agree that it is licensed under Apache-2.0, the license of this repository
  (section 5 of the license); no separate agreement is needed.
- Keep shell and Python files on LF line endings; CRLF breaks them on the pod.
- Say in the pull request which GPU and which settings you ran it on, and include the timing lines from the server
  log if the change touches the generation path.
- Do not add brand or third-party product images to `garments/`.
